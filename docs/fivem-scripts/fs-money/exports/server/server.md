# Server Exports

Use these functions to modify or check a player's money.

### Using These Exports
Example call:

```lua
exports['FS-Money']:getMoney('cash', source)
```

## Available Exports
- [addMoney](./addMoney.md)
- [getMoney](./getMoney.md)
- [removeMoney](./removeMoney.md)
- [setMoney](./setMoney.md)
- [transferMoney](./transferMoney.md)
