# FS-Lib

![Github All Releases](https://img.shields.io/github/downloads/FearlessNite345/FS-lib/total.svg?style=for-the-badge)
![GitHub Downloads (all assets, latest release)](https://img.shields.io/github/downloads/fearlessnite345/fs-lib/latest/total?style=for-the-badge)
![GitHub Release](https://img.shields.io/github/v/release/fearlessnite345/fs-lib?style=for-the-badge)

FS-Lib is a collection of helper functions used across many FearlessDev scripts. It aims to simplify common FiveM tasks so you can focus on your own gameplay features.

## Getting Started
- [Installation](./Installation.md)
- [API Reference](/fivem-scripts/fs-lib/exports)

## Features
- Utilities for working with entities, locations and player data.
- Ready-to-use drawing helpers for markers and text.

:::tip
FS-Lib works in both Lua and JavaScript environments.
:::

:::note
FS-Lib is under active development and may introduce breaking changes. Check the changelog when updating.
:::
