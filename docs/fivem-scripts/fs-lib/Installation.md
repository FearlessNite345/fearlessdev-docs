Below are the steps to install FS-Lib.

## Step 1: Download FS-Lib
In order to download FS-Lib [Click Here](https://github.com/FearlessNite345/FS-Lib/releases/latest)

## Step 2: Extract the Resource
The `.zip` file will contain the resource named `FS-Lib`. Drag and drop this resource into your `resources` folder.

:::warning
**DO NOT** rename this resource or `FS-Lib` will not work.
:::

## Step 3: Add this resource to `server.cfg`
Navigate to your server's `server.cfg` and add the following line into the file
```
ensure FS-Lib
```

## Done
FS-Lib will now be installed and working!
