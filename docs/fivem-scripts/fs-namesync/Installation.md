Below are the steps to install FS-NameSync.

## Step 1: Download FS-NameSync
In order to download FS-NameSync [Click Here](https://github.com/FearlessNite345/FS-NameSync/releases/latest)

## Step 2: Extract the Resource
The `.zip` file will contain the resource named `FS-NameSync`. Drag and drop this resource into your `resources` folder.

## Step 3: Add this resource to `server.cfg`
Navigate to your server's `server.cfg` and add the following line into the file
```
ensure FS-NameSync
```

## Done
FS-NameSync will now be installed and working!
