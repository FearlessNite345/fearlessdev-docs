# FiveM Scripts

Browse the following resources built by FearlessDev. Select a script to view detailed installation and configuration instructions.

- [FS-InteriorManager](fs-interiormanager/fs-interiormanager.md) - Manage interior teleport locations and entry points.
- [FS-LBPhoneNumAssigner](fs-lbphonenumassigner/fs-lbphonenumassigner.md) - Automatically assign LB Phone numbers to players.
- [FS-Lib](fs-lib/fs-lib.md) - Utility library shared across many FearlessDev resources.
- [FS-LoadingScreenV2](fs-loadingscreenv2/fs-loadingscreenv2.md) - Customizable loading screen with player tips and music.
- [FS-Money](fs-money/fs-money.md) - Simple bank and cash system for FiveM servers.
- [FS-NameSync](fs-namesync/fs-namesync.md) - Keep player names consistent with Discord.
- [FS-NowOpen](fs-nowopen/fs-nowopen.md) - Directory system for businesses currently open.
- [FS-RackControl](fs-rackcontrol/fs-rackcontrol.md) - Weapon racking with configurable loadouts.
- [FS-SpawnSelector](fs-spawnselector/fs-spawnselector.md) - Let players choose where to spawn.
